# Contributing

Please keep changes deterministic and avoid adding provider credentials, archives, user content, deployment targets, or machine-specific paths to the repository.

Before opening a pull request, run `pnpm run test:offline` in a clean virtual environment. Explain any change to a state-machine contract, persistence boundary, scheduling policy, or static-identity rule and add a focused regression test.

By submitting a contribution, you confirm that you have the right to contribute it and agree that it is provided under the repository's MIT License.
